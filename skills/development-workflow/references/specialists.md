# 开发专长目录

| 专长 | 输入与交付 | 资源及边界 |
|---|---|---|
| [openspec-explore](../../openspec-explore/SKILL.md) | 问题、背景、已有项目；探索和判断 | 保持讨论，不因“探索”开始实现 |
| [openspec-propose](../../openspec-propose/SKILL.md) | 明确需求/变更名；proposal、design、tasks | 读取 CLI 的 schema 和实际输出路径，不猜目录 |
| [openspec-apply-change](../../openspec-apply-change/SKILL.md) | 已选变更与 contextFiles；实现及任务状态 | 依赖 openspec CLI；workspace-planning 且无编辑根时停止实施 |
| [openspec-sync-specs](../../openspec-sync-specs/SKILL.md) | 主规格与增量规格；部分合并 | 先读两端，保留无关内容；不归档 |
| [openspec-archive-change](../../openspec-archive-change/SKILL.md) | 完成状态、任务与规格同步状态；归档 | 未完成或未同步时展示具体影响；不把通用“完成了”擅自解释为归档授权 |
| [tdd](../../tdd/SKILL.md) | 已选接口与可观察行为；红绿重构 | `tests.md`、`mocking.md`、`interface-design.md` 等；未要求 TDD 时不强行添加流程 |
| [project-context-maintainer](../../project-context-maintainer/SKILL.md) | AI 项目说明需求；AGENTS.md | 保留项目选定的文档维护策略，不为普通 README 修改触发全库扫描 |
| [grill-with-docs](../../grill-with-docs/SKILL.md) | 方案与已有领域模型；术语、必要 ADR | `CONTEXT-FORMAT.md`、`ADR-FORMAT.md`；只在用户要质询方案时使用，不默认不停追问 |
| [write-swift](../../write-swift/SKILL.md) | Swift 工具链、代码与并发问题；修复 | 技术附属，与 UI 审美分开；不为了套示例升级编译器 |
| [karpathy-guidelines](../../karpathy-guidelines/SKILL.md) | 现有代码改动范围；实现约束 | 自包含指导，不替代实际测试 |

目录提供选择信息，不复制专长正文，也不保证所有第三方工具已经安装。
