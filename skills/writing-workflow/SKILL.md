# 写作整理总入口

用于已有文字的自然表达、去模板或风格调整。先确认原文、语言、读者与应保留的事实；普通问答、技能仓库整理和代码任务不因出现“AI”而触发本流程。

## 选择

- 中文为主，尤其中文学术表达或社交平台文体：读取 [humanize-chinese](../humanize-chinese/SKILL.md)。
- 英文或中英混合，重点检查冗词、句式和宣传式表达：读取 [writing-anti-ai](../writing-anti-ai/SKILL.md)，只加载当前语言的 patterns 与 examples。
- 中文仍有具体难点时，可补充 writing-anti-ai 的中文模式参考；不要把两个完整流程连续套在同一段文字上。

二者职责互补，保留原来源和独立更新，不将评分相近当作可删除的重复。规则与引用的使用限制见 [核对说明](references/validation.md)。

## 执行边界

保留作者立场、数据、引用、专业术语和不确定性；不为增加“人味”虚构第一人称经历、意见、来源或细节。三项并列、破折号与常见连接词是上下文判断线索，不是机械禁用表。

文风判断不能证明作者身份，也不能承诺降低某个检测器的百分比。若用户提供真实检测输出，只就该输出说明范围；不把主观自然度分当检测器结果。中文专长提及的 CLI 脚本不在本地包内，不能声称已执行或自动下载补齐，采用其可用的人工改写路径即可。

默认只返回修改后的文字和必要说明；要求保存文件时再写到指定位置。核对数字、引用、事实和语气是否漂移；未做独立评价时明确这是当前作者的检查，不宣称盲评优胜。
