# 技能管理总入口

保留 f-d-u-d 旧名称，按用户本次目标选择工作阶段；不要求每个请求都走完“搜索—安装—开发—删除”。

## 分派

| 目标 | 选择与交付 |
|---|---|
| 查找是否有能完成任务的技能 | [find-skills](../find-skills/SKILL.md)，候选、用途与来源证据 |
| 创建/改写一个技能，验证触发或行为 | 实际宿主提供的 `skill-creator`；本地扩展版见 [入口](../skill-creator/SKILL.md) |
| 对已有技能评分、分组、蒸馏和入口整合 | [skill-curator](../skill-curator/SKILL.md)，绑定版本的证据和验证 |
| 安装前检查外部技能 | [skill-vetter](../skill-vetter/SKILL.md)，先读代码与依赖；缺扫描器时明确扫描覆盖不足，不报告 SAFE |
| 已选来源的导入与启用 | 优先已有 Skill Shelf 的预览/导入流程或宿主已提供的安装器；检查真实能力，不猜 API |
| 删除或清理 | 先识别物理内容、联接、来源与引用，列出具体对象和保留方案；在授权范围内使用统一库管理器的回收流程 |

## 安装与使用

用户明确选定来源和安装范围后推进，不重复征求已给出的授权。未知来源先检查指令、脚本、副作用和许可证；热度和安装量只作候选信息，不代替代码与任务适配检查。只有用户要找外部技能时才联网，先检查已安装能力。

当前环境使用统一库和四个 Agent 的目录联接，沿用配置的路径，不硬编码 `.agents/skills`，不通过全局 CLI 绕开统一库另装物理副本。安装完成后验证真实入口、必要资源、联接目标、来源记录及管理器扫描统计。

需要使用指南时就地给出本次任务所需的简短示例；不自动往桌面写跟踪文件或大篇幅提示词指南。用户只是安装时，不自动开展项目开发。

## 清理边界

“任务完成”不是删除授权；跟踪清单也不证明某个文件可删。删除前检查其他入口引用、本地改写和内容指纹。来源更新不能静默覆盖本地改造，分数低也不自动删除。联接与物理文件分别处理，不递归删除可能指向统一库的 Agent 路径。

只对真正发生的搜索、安装、使用或清理报告结果；未执行的阶段不补一个虚假的通过状态。
