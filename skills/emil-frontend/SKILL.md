# Emil 前端入口兼容转接

本地 UI 系列已统一使用 [ui-design](../ui-design/SKILL.md) 进行任务选择。

读取该入口并按用户原始目标、平台、改动范围和已选技术继续执行；明确点名的专长直接保留。普通 UI 请求不自动启用 Taste、选库或多方案原型等需要显式请求的专长。

如果 ui-design 未安装，明确报告缺少总入口；用户明确点名的现有专长仍可直接读取，不猜测其他机器的绝对路径或自动安装。

此兼容入口只转接一次，ui-design 直接选择实际专长，避免在两个入口之间来回加载。
